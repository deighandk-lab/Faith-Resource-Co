# Faith-Resource-Co

Faith Resource Co. is a modern Christian online bookstore and resource platform dedicated to providing faith-based books, devotionals, stationery, journals, and inspirational resources to individuals, churches, ministries, schools, and communities.

Formerly known as **Faith Resource Centre**, this project represents the continuation of a meaningful legacy built on faith, knowledge, purpose, and community impact.

---

## 🌍 Project Overview

This website was created as a modern online storefront for Faith Resource Co. featuring:

* Premium bookstore-inspired design
* Responsive layout
* Shop Online page
* Learn More page
* Contact page
* WhatsApp ordering integration
* Social media integration
* Christian-focused branding

---

## 📄 Pages Included

* `index.html` — Main landing page
* `shoponline.html` — Online shop page
* `learn-more.html` — Brand story and mission page

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/faith-resource-co.git
```

### 2. Open the Project

Open the project folder in:

* VS Code
* Sublime Text
* or any preferred code editor.

### 3. Run the Website

Open:

```text
index.html
```

in your browser.
